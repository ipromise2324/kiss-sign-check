# How to read a bytes argument that holds no call. Written by hand from each protocol's source; see README.md.
# Only printable ASCII is allowed, comments included.
#
#   <function> <argument> abi <types>                 the bytes are abi.encode(<types>)
#   <function> <argument> packed <type> <type> ...    the bytes are abi.encodePacked of these fixed-size types
#   <function> <i>,<j> commands <table>               byte k of argument i picks the layout of element k of argument j
#   <table>: <byte> <NAME> <layout>                   one row of a command table; the layout is one of the three above,
#                                                     where `commands <table>` reads the bytes as abi.encode(bytes, bytes[])
#
# <function> is a full signature, as cast sig takes it. Several abi or packed lines for one argument are tried in order.
